# PA LINE Crew & Command

`index.html` is the canonical private PA LINE operations application. Do not replace it with `src/app.js`; `src/` contains legacy development snapshots.

Trever Stribing is the sole full-control Command administrator. All other active member profiles use the simplified Crew portal.

Command navigation:
- Home
- Shows
- Road
- Band
- Office

Crew navigation:
- Home
- Schedule
- Shows
- Band
- My Portal

Existing operational tools remain available inside those folders, including offers, confirmed shows, calendars, touring, markets, contacts, communications, Weekly Ops, rehearsals, meetings, Crew Chat, Songbook, lineups, artist profiles, notifications, account settings, and data recovery tools.

Private access requires secure profile sign-in.
