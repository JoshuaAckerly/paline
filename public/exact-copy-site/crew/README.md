# PA LINE CREW + COMMAND Beta v7.25

`index.html` is the current private beta runtime. Do not replace it with `src/app.js`; `src/` contains legacy development snapshots.

Launch the integrated beta from the package root with `START_PA_LINE.bat`.

Current systems include Master Admin, Crew Admin/member portals, secure sign-in, Quick Access, notifications, Master reminders, calendar, contacts, booking pipeline, communications, offers/shows, rehearsals, meetings, Crew Chat, Weekly Ops, Songbook/setlists, practice audio, custom roles, merch/attendance planning, public booking bridge, and Data Vault.

Run `npm run validate` to validate the actual integrated runtime.
