# RUN THIS FIRST

1. Install Node.js if you do not already have it.
2. Open this folder in Visual Studio Code.
3. Open the VS Code terminal.
4. Run:

```bash
npm run validate
npm run dev
```

5. Open `http://localhost:5174`.
6. Open `COPILOT_START_PROMPT.md` and paste it into Copilot Chat.

No package installation is required for the current prototype.
